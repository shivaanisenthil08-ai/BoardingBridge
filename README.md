 BoardingBridge – Airline Management System

About the Project
BoardingBridge is a web-based Airline Management System developed as part of an internship project. It provides users with a simple and user-friendly platform to search for flights, book tickets, select seats, manage reservations, and access their profiles.

The project aims to simplify the airline reservation process through an organized interface and database integration.

Features
- User Registration and Login
- User Dashboard
- Flight Search
- Flight Booking
- Interactive Seat Selection
- View My Bookings
- Cancel Reservations
- User Profile Management

Technologies Used
- Frontend: Web Technologies
- Backend: Node.js
- Database: MySQL
- Deployment: Netlify

Installation and Setup

1. Clone the Repository

    git clone <your-repository-url>

2. Navigate to the Project Directory

    cd BoardingBridge

3. Install Backend Dependencies

    cd backend
    npm install

4. Configure MySQL
- Start your MySQL server.
- Create the required database.
- Configure the database connection details in the backend.

5. Start the Backend Server

    node server.js

6. Run the Frontend
Open the frontend folder in your code editor and run the application using the appropriate development setup.
